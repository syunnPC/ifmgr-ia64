IA-64/EFI DOS 4.0
BOOTIA64.EFI -> IO.SYS -> MSDOS.SYS -> COMMAND.COM (native IA-64 PE32+).
Try HELP, APITEST, SYSTEST and ENVTEST. SHUTDOWN flushes the disk and exits.
8086 COM/MZ programs run in VDM.EXE on processors with IA-32; EFI services remain active.
See the host README.md and source code for build instructions and the ABI.
